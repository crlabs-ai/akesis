# Official Akesis Terminology

To maintain consistency across Product, Architecture, Backend, AI Prompts, APIs, Database Schemas, and UI, the following vocabulary is authoritative:

| Term | Official Definition |
| :--- | :--- |
| **CI Failure** | An event where an automated continuous integration pipeline execution terminates with a non-zero exit code or error status. |
| **Incident** | A unique, tracked Akesis entity representing an ingested CI failure event from a specific repository, branch, and commit. |
| **Log Stream** | The raw, unstructured stdout/stderr output emitted by a failed CI workflow job. |
| **Diagnosis** | The structured output of the log analysis engine, containing the root cause error category, failed file paths, line numbers, and error signature. |
| **Remediation** | The end-to-end process of diagnosing a failure, generating a code fix, validating it, and delivering a Pull Request. |
| **Patch** | A unified git diff (`.diff` / `.patch`) representing the exact minimal code modifications generated to resolve a diagnosis. |
| **Sandbox** | An isolated, ephemeral containerized runtime environment (Docker/microVM) where a patch is applied and tested against the failure. |
| **Validation** | The automated execution of the build, lint, or test command inside the sandbox to verify that a patch compiles and passes. |
| **Confidence Score** | A normalized floating-point metric ($0.0$ to $1.0$) generated by the agent runtime representing certainty in the diagnosis and fix. |
| **Human Approval** | The explicit action taken by an authorized developer reviewing and merging the Akesis-generated Pull Request. |
| **Quarantine** | The action of isolating a non-deterministic (flaky) test or unresolvable failure to prevent it from blocking the main delivery pipeline. |
| **Agent Runtime** | The deterministic state-machine coordinator managing LLM reasoning loops, tool invocations, and execution boundaries. |
| **Workflow** | The sequence of tasks executed by the Akesis engine for a single incident (Ingest → Diagnose → Generate → Validate → Deliver). |
