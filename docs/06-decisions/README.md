# Architecture Decision Records (ADR) Index

This directory contains the authoritative, immutable log of all architectural decisions made for Akesis.

---

## ADR Lifecycle & Format
Every ADR follows the MADR (Markdown Architectural Decision Records) format:
*   **Status:** `Proposed` | `Accepted` | `Rejected` | `Deprecated` | `Superseded`
*   **Structure:** Title $ightarrow$ Status $ightarrow$ Context $ightarrow$ Decision $ightarrow$ Alternatives Considered $ightarrow$ Consequences.
